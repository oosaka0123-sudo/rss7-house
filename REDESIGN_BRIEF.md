# RSS7 HOUSE — Reconstruction Brief

## Goal
Create a high-impact design demo for a fictional premium Japanese custom-home brand. This is an art-direction showcase, not a conservative production template.

## Current failures to remove
- Broken multi-line English marquee that looks like source/debug text.
- Touch-triggered `VIEW PROJECT` overlay that becomes a black obstruction.
- Literal house + number 7 logo with weak brand distinction.
- Effects added independently without one coherent visual system.

## Required process
1. Brand positioning and three logo directions.
2. Wireframe and content rhythm.
3. Interaction prototype for desktop and touch.
4. Independent Claude / Jules / Codex proposals via separate branches.
5. Copilot review of candidate PRs.
6. Integration, responsive QA, performance QA, deploy.

## Art direction
Architectural editorial, Japanese restraint, one bold experimental device, strong typography, asymmetrical grid, generous negative space, tactile motion. Avoid literal roof icons, generic rounded cards, random marquees, sticky hover, glassmorphism, and effects without meaning.

## Acceptance
- No UI fragment can look like code or unfinished output.
- Logo works at 24px and in monochrome.
- Touch has no hover-only content.
- Motion remains coherent and disabled by reduced-motion.
- First content is visible immediately with JavaScript disabled.
