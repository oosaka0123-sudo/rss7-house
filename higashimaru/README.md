# 東丸（あずままる）Concept Preview

乗合船「東丸」の公開前コンセプトです。GitHub Pages の `/higashimaru/` 配下で動作する、HTML / CSS / JavaScript の静的サイトです。

## 最重要ルール

- **`higashimaru/index.html` は保護対象。ユーザーから明示的な変更指示がない限り変更しない。**
- 下層ページの改修・予約システム比較・釣果運用の検討を理由に、トップページへCTA・動画・文言・ナビ項目を自動追加しない。
- トップを変更する必要が生じた場合は、先に変更内容を明示してから作業する。

## 現在の公開構成

- `index.html` — トップ（保護対象）
- `schedule.html` — 空席情報。本番運用イメージ、残席表示、予約導線
- `catch.html` — 釣果。最新釣果、魚種・サイズ/匹数・船長コメント、空席/予約導線
- `guide.html` — 初めての方。予約〜集合〜乗船、持ち物・服装・安全案内
- `reservation.html` — 予約ページ。3ステップ予約プレビュー（外部送信なし）
- `client-reservation-options.html` — サイト制作クライアント向け予約システム3方式比較
- `client-catch-guide.html` — サイト制作クライアント向け釣果掲載方式比較

## クライアント向けの現在方針

### 予約システム

クライアントがサイト制作時に選択する。

1. 自社専用予約システム
2. fishbank 連携
3. 釣割連携

一般の乗船客が3方式から選ぶ画面ではない。予約ページ下部の大きな事業者向けカードから比較ページへ誘導する。

### 釣果掲載

標準推奨は「自社サイトを釣果の正本」にする方式。

- スマホから写真1〜6枚
- 日付
- 魚種
- サイズ / 匹数 / 竿頭など確認できる数字
- 船長コメント

を1回入力し、自社サイトへ公開。その内容をInstagram等へ再利用する設計を想定する。Instagramだけ、外部ブログだけに依存する構成は標準にしない。

## 現在の表示方針

正式情報が未確定のため、料金・残席・出船時刻・釣果数値等は実データとして捏造しない。

- デモ値は `SAMPLE` / `掲載イメージ` と明記
- 正式公開時に実情報へ差し替える
- 釣果の正確なポイントなど、公開すべきでない情報は載せない

## 公開前に必要な正式情報

- 港・集合場所・駐車場
- 電話番号・LINE等の連絡先
- 料金、定員、対象魚、出船時間
- レンタル、仕掛け、エサ、氷等の提供内容と料金
- 東丸の実写素材、船長情報
- 予約方式の最終決定
- キャンセル規定、欠航時の連絡方法
- プライバシーポリシー、必要な利用規約

## 素材

`media/*.webp` / `media/*.mp4` はコンセプト確認用素材です。正式な実写素材入手後に差し替えます。

現行の下層ページでは、外部動画に依存せずリポジトリ内の動画ファイルを利用しています。トップページについては保護対象のため、明示指示なく動画ソースを変更しません。

## 完成判定（デモ段階）

現時点では、クライアントへ「完成後の情報設計・予約方式・釣果運用」を見せるデモとして使用可能。

正式公開の完成条件は、上記の正式情報と実写素材を受領し、予約方式を確定したうえで、実データ差し替え・リンク・法務ページ・最終端末QAを完了すること。
