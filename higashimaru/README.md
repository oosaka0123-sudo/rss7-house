# 東丸 Concept Preview

乗合船「東丸」の公開前コンセプトラフです。GitHub Pages の `/higashimaru/` 配下で動作する、HTML / CSS / JavaScript の静的サイトです。

## 現在の仕様

- 全画面の航走動画ヒーロー
- 90pxスクロール後に現れる半透明ヘッダー
- モバイル用フルスクリーンメニュー
- 空席情報、釣果イメージ、船上体験、初回案内、予約CTA
- 港・釣り人・船上クーラーの生成イメージギャラリー
- 便の希望→人数・経験→確認の3ステップ予約プレビュー（外部送信なし）
- `prefers-reduced-motion` 対応

## 公開前に必要な正式情報

- 港・集合場所
- 電話番号・LINE
- 料金、定員、対象魚、出船時間
- 東丸の実写素材、船長情報
- 予約規約、キャンセル規定、プライバシーポリシー

`media/*.mp4` と `media/*.webp` はコンセプト確認用の生成素材です。実素材入手後、同名ファイルへ差し替えます。
