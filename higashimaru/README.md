# 東丸（あずままる）Concept Preview

乗合船「東丸」の公開前コンセプトラフです。GitHub Pages の `/higashimaru/` 配下で動作する、HTML / CSS / JavaScript の静的サイトです。

## 現在の仕様

- 全画面の実写航走動画ヒーロー
- 初期表示の白いロゴ／ハンバーガーメニューから、90pxスクロール後に半透明ヘッダーへ切り替え
- トップ、空席情報、釣果、船上体験・初回案内、予約の5ページ構成
- 港・釣り人・船上クーラーの生成イメージギャラリー
- 便の希望→人数・経験→確認の3ステップ予約プレビュー（外部送信なし）
- `prefers-reduced-motion` 対応

## 公開前に必要な正式情報

- 港・集合場所
- 電話番号・LINE
- 料金、定員、対象魚、出船時間
- 東丸の実写素材、船長情報
- 予約規約、キャンセル規定、プライバシーポリシー

## 動画素材

動画は Coverr の商用利用可能なストック映像を外部配信で使用しています。映像は東丸の実船・船長・実際の運航を撮影したものではありません。

- Boat in the sea: https://coverr.co/videos/boat-in-the-sea-isvm2paqun
- Fisherman in a small boat: https://coverr.co/videos/fisherman-in-a-small-boat-xoxw3wkpwn
- Sunset over the sea: https://coverr.co/videos/sunset-over-the-sea-wv5xilvt8d

`media/*.webp` はコンセプト確認用の生成素材です。正式な実写素材入手後に差し替えます。
