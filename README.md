# RSS7 HOUSE Demo

関西の注文住宅ブランド「RSS7 HOUSE」を想定した営業デモサイトです。HTML/CSS/JavaScriptのみで動作し、GitHub Pagesへそのまま公開できます。

## ローカル確認

```bash
python3 -m http.server 8080
```

`http://localhost:8080` を開きます。

## 公開前に差し替える項目

- 会社名・住所・電話番号・免許/許可番号
- 施工事例、性能値、保証内容
- プライバシーポリシー
- フォーム送信先
- OGP画像、favicon、独自ドメイン
